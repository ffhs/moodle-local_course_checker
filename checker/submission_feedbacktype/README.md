# 📚 Checker Submission Feedback for Moodle: Subplugin of the Local Course Checker Plugin

This plugin checks if a submission activity has set a feedback type.

---

## ⚙️ Requirements

- Moodle **4.0 or higher**
- A working **cron job**
- PHP extension `curl` (required for the Broken Links checker)
